# CADET รด.หัวใจอาสา — เว็บโครงการ

เว็บแนะนำโครงการ (HTML/CSS/JS ล้วน ไม่มีเซิร์ฟเวอร์ ไม่เก็บข้อมูลนักเรียน)

- `index.html` โครงเว็บตามโมเดล CADET: โมเดล 5 ขั้น, ภารกิจ 3 ระดับ, เว็บ 5 ระบบ, ตัวชี้วัด, แผน 16 สัปดาห์, แฟ้มหลักฐาน
- `assets/logo.png` โลโก้ (พื้นหลังโปร่งใส)
- `assets/photos/` วางรูปตามชื่อ `mission-1..3.jpg`, `gallery-1..6.jpg`, `teacher.jpg` รูปจะแสดงเองโดยไม่ต้องแก้โค้ด
- ผลการทดลองยังเป็นช่อง "รอข้อมูลจริง" ใส่เมื่อมีข้อมูลที่เก็บจริงเท่านั้น
