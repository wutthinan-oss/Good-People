# CADET ภารกิจทำดี

เว็บแอป (PWA) สำหรับโมเดล CADET รด.หัวใจอาสา: เห็นปัญหา รับภารกิจ ลงมือจริง เรียนรู้เพื่อส่วนรวม

- ภารกิจ 12 สัปดาห์ ผ่านขั้น C-A-D-E-T บันทึกกิจกรรมและความดี ประเมินความรับผิดชอบ ความซื่อสัตย์สุจริต จิตสาธารณะ ก่อน-หลัง
- ข้อมูลเก็บในเครื่องผู้ใช้ ไม่ส่งไปเซิร์ฟเวอร์ ไม่มีรายชื่อนักเรียนในซอร์สโค้ด
