# สร้างสรรค์คนดี

เว็บแอป (PWA) สำหรับบันทึกกิจกรรมคุณธรรม ประเมินคุณลักษณะก่อน-หลัง และสร้างเล่มผลงานนวัตกรรมตามโครงสร้าง A–D (พิมพ์ PDF หรือดาวน์โหลด Word)

- ข้อมูลเก็บในเครื่องผู้ใช้ (localStorage) ไม่ส่งไปเซิร์ฟเวอร์ใด
- ไม่มีรายชื่อนักเรียนในซอร์สโค้ด ให้นำเข้าในแอปเอง
- ปุ่ม "โหลดข้อมูลตัวอย่าง" ใช้นักเรียนสมมติ และเล่มจะมีลายน้ำ "ตัวอย่าง"
- ติดตั้งบนมือถือ: เปิดเว็บแล้วเลือก "เพิ่มลงหน้าจอหลัก"
